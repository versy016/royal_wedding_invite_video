# Gemini prompts – scroll-down sections for Sanchi & Mridul's invite

## How to use

1. Open Gemini (image generation / "Nano Banana").
2. Attach `01_style_reference_final_frame.png` and `02_video_doors_opening.png` from this folder.
3. Paste the **STYLE LOCK** paragraph first, then ONE section prompt below it.
4. Generate one image per chat message. If the style drifts, re-attach the reference images and say
   "Match the reference images more closely – same palette, lighting and painterly finish."
5. Save each result with the suggested filename into the project folder.

  continuing the garden naturally at the bottom."
